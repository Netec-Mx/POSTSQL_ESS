# PostgreSQL 

## Plataforma de laboratorios

Te damos la bienvenida a la **plataforma de laboratorios** del curso **PostgreSQL**. Aquí podrás explorar diferentes tecnologías a través de prácticas guiadas. ¡Desarrolla tus habilidades y lleva tus conocimientos al siguiente nivel!

---

<br/>

## Lista de **Prácticas**

Cada uno de estos laboratorios está diseñado para ofrecerte una experiencia práctica. Haz clic en los enlaces para comenzar.


<br/>

### [Práctica 1.1. Instalación de PostgreSQL versión 18 y PgAdmin en Windows](Modulo01/README.md) 

- Esta práctica guía al estudiante a través del proceso completo de instalación y configuración del entorno de desarrollo PostgreSQL 18 en Windows. PostgreSQL es uno de los sistemas de gestión de bases de datos relacionales de código abierto más avanzados y ampliamente utilizados en la industria. Al finalizar este laboratorio, tendrás un entorno completamente funcional con PostgreSQL 18 y PgAdmin 4, listo para desarrollar y gestionar bases de datos **profesionales**. Esta configuración será la base para todos los laboratorios posteriores del curso.

- ⏱️ **Duración estimada**: 90 min.

<br/>


### [Práctica 2.1 Diseño de una base de datos relacional para una tienda de barrio o conveniencia](Modulo02/README.md)

- En este laboratorio, diseñarás una base de datos relacional completa para una tienda de barrio o conveniencia, aplicando principios de modelado entidad-relación y normalización. Identificarás entidades clave como Productos, **Categorías**, Clientes, Ventas, Proveedores e Inventario, establecerás relaciones entre ellas, y crearás un diagrama ER profesional. Este ejercicio simula un escenario real de diseño de bases de datos, preparándote para implementar sistemas de **información** efectivos en entornos comerciales.

- ⏱️ **Duración estimada**: 110 min.


<br/>

### [Práctica 3.1 Creación de la base de datos diseñada en la práctica anterior](Modulo03/README.md)

- En este laboratorio implementarás físicamente la base de datos de la tienda de barrio que diseñaste en el laboratorio anterior. Utilizarás SQL DDL (Data **Definition** Language) para crear la base de datos, definir todas las tablas con sus tipos de datos apropiados, establecer constraints de integridad, y poblar las tablas con datos de prueba. Esta práctica te permitirá transformar un diseño conceptual en una base de datos funcional en PostgreSQL, aplicando principios de **integridad** referencial y buenas prácticas de modelado físico.

- ⏱️ **Duración estimada**: 110 min.


<br/>


### [Práctica 4.1 Ejercicios aplicados a la base de datos del curso](Modulo04/README.md)

- Este laboratorio proporciona práctica intensiva en consultas SQL mediante la ejecución de ejercicios progresivos sobre la base de datos tienda_barrio. Los **estudiantes** aplicarán técnicas de consulta SELECT desde operaciones básicas hasta consultas complejas que combinan filtros, agregaciones, agrupamientos y **funciones** integradas. Esta práctica consolida las habilidades fundamentales de **consulta** necesarias para extraer información significativa de bases de datos **relacionales**, preparando a los estudiantes para análisis de datos más avanzados.

- ⏱️ **Duración estimada**: 110 min.


<br/>


### [Práctica 5.1 Ejercicios aplicados a la base de datos del curso](Modulo05/README.md)

- Este laboratorio proporciona práctica intensiva en la manipulación de datos **utilizando** sentencias UPDATE y DELETE en PostgreSQL. Los estudiantes ejecutarán una serie de ejercicios progresivos que abarcan desde actualizaciones simples hasta operaciones complejas con subconsultas, manejo de transacciones y estrategias de eliminación segura. El enfoque está en desarrollar habilidades para modificar datos de manera controlada, comprendiendo las implicaciones de **integridad** referencial y aplicando buenas prácticas para prevenir pérdida de datos.

- ⏱️ **Duración estimada**: 95 min.


<br/>

### [Práctica 6.1 Ejercicios aplicados a la base de datos del curso](Modulo06/README.md)

- En este laboratorio aplicarás técnicas SQL avanzadas sobre la base de datos de la tienda creada en laboratorios anteriores. Ejecutarás una serie de ejercicios **progresivos** que incluyen JOINs complejos entre múltiples tablas, creación de vistas para simplificar consultas recurrentes, subqueries correlacionadas y no **correlacionadas**, operadores de conjuntos, expresiones CASE, funciones window para análisis de tendencias, y Common Table Expressions (CTEs) para descomponer consultas complejas. Este laboratorio consolida todas las habilidades de consulta SQL desarrolladas en el curso y las aplica a escenarios prácticos de análisis de datos empresariales.

- ⏱️ **Duración estimada**: 100 min.

<br/>


### [Práctica 7.1 Aplicación de lo aprendido en el curso](Modulo07/README.md)

- Este laboratorio representa el proyecto integrador final del curso, donde **aplicarás** todos los conocimientos adquiridos para diseñar e implementar desde cero una base de datos completa para un sistema de reservas de alojamientos (tipo Airbnb/Booking). Diseñarás el modelo entidad-relación, implementarás la base de datos con todas sus tablas y relaciones, insertarás datos de prueba realistas y crearás consultas complejas para reportes de negocio. Este proyecto consolida las habilidades de diseño, normalización, implementación DDL, manipulación DML y consultas avanzadas SQL desarrolladas a lo largo del curso.

- ⏱️ **Duración estimada**: 155 min.
